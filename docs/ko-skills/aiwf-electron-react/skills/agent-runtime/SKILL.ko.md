# 에이전트 런타임 통합

> 휴먼 리뷰용 한글 번역입니다. 실행 원문: [원문](../../../../../plugins/aiwf-electron-react/skills/agent-runtime/SKILL.md). 번역과 자동 검사는 승인을 뜻하지 않으며, 검토 상태와 원문 SHA256은 [관리 목록](../../../manifest.json)에서 확인합니다.

- 식별자: `agent-runtime`
- 설명: 검증된 어댑터를 통해 Sally·PI 또는 선택한 코딩 에이전트 런타임을 Electron에 연결하고 세션·스트리밍·도구 동의·취소·정리를 다룹니다.


$ARGUMENTS에서 선택한 런타임을 통합합니다. 먼저 설치 패키지·CLI 도움말·프로토콜 정의·실제 import·daemon 소유 관계를 조사합니다. Sally daemon/protocol과 PI는 가능한 백엔드이며 필수 패키지명이나 서로 바꿔 쓸 수 있는 API가 아닙니다. 모듈 이름·RPC 메서드·이벤트명·인증을 추측하지 않습니다. 근거가 없으면 필요한 자료를 정확히 기록하고 요청이 허용한 계약/mock 경계까지만 구현합니다.

## 어댑터와 전송

1. Renderer 동작에서 preload/main을 거쳐 런타임에 도달하고 돌아오는 실제 실행 경로를 문서화합니다. 세션 생성·재개·취소·도구 승인·첨부 같은 지원 기능을 나열하며 미지원 기능은 UI와 테스트에 명시합니다.
2. 어댑터를 main 또는 소유한 worker/서비스 프로세스에 둡니다. Provider 이벤트를 안정적인 세션/실행/이벤트 식별자가 있는 앱 소유의 직렬화 가능한 메시지로 정규화합니다. IPC 요청과 런타임 수신 이벤트 모두 크기 제한이 있는 스키마로 검증합니다. 잘못된 메시지·초과 크기·알 수 없는 버전·다른 세션 트래픽은 상태 변경 전에 거부합니다.
3. `ws`는 런타임에 문서화된 endpoint/인증을 사용하며 원격 연결에는 TLS를 씁니다. 앱이 로컬 서비스를 소유하면 loopback에 바인딩하고 인증된 접근을 적용합니다. 브라우저 세션 쿠키는 daemon 권한이 아닙니다. Renderer가 토큰이나 실행 경로를 제어하지 못하게 합니다.
4. 스트림 순서를 유지하고 재전송을 중복 제거하며 도구 경계와 최종 결과를 잃지 않도록 backpressure·이벤트 병합을 적용합니다. 부분 도구 인자는 유효해질 때까지 버퍼링하며 불완전한 스트리밍 JSON을 실행하지 않습니다. 비밀을 노출하지 않고 추론·도구 표시 데이터를 정규화합니다.
5. 승인과 취소는 런타임의 실제 프로토콜로 전달합니다. 런타임 권한 정책을 유지하며 모델이 만든 승인 이벤트는 권한을 부여하지 않습니다. 시간 초과·연결 해제는 재확인 전까지 불명 또는 실패 상태로 표시합니다. 버튼 클릭만으로 실행을 취소 완료로 표시하지 않습니다. 재연결 후 재개는 지원되는 경우에만 안정적인 식별자를 사용하며 도구 부작용을 중복 실행하지 않아야 합니다.
6. 소유 관계를 추적합니다. 외부 관리 daemon에서는 연결만 해제하고, 앱이 소유하며 승인된 범위에 속한 자식 프로세스/세션만 중지합니다. 창 닫힘·재시작 시 구독과 대기 요청을 정리하고 로그의 비밀을 가리며 문서화된 보존 정책을 적용합니다. 기존 main 측 자격증명 저장소가 있으면 사용합니다. 없다면 실제 자격증명을 추가하기 전에 저장 방식의 결정을 기록하며 저장소가 이미 존재한다고 가정하지 않습니다.

## 검증

기록·합성 이벤트부터 사용합니다. Delta·잘못된 메시지·중복/순서 역전·연결 해제/재연결·거부된 도구 동작·미지원 기능·취소 경합·daemon 종료를 검증합니다. 부작용 중복과 다른 세션의 오래된 이벤트 유입이 없는지 확인합니다. 선택한 런타임이 설치·설정되고 접근과 비용이 승인된 경우에만 실제 smoke를 실행합니다. 어댑터 버전·프로토콜 근거·mock와 실제 결과·지원 기능·막힌 조건을 보고합니다. `sync-docs` 또는 직접 작업으로 영향받는 UC/TC·아키텍처 문서를 갱신합니다.
