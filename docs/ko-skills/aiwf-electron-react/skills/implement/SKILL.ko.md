# Electron 유스케이스 구현

> 휴먼 리뷰용 한글 번역입니다. 실행 원문: [원문](../../../../../plugins/aiwf-electron-react/skills/implement/SKILL.md). 번역과 자동 검사는 승인을 뜻하지 않으며, 검토 상태와 원문 SHA256은 [관리 목록](../../../manifest.json)에서 확인합니다.

- 식별자: `implement`
- 설명: 선택한 코딩 에이전트 런타임을 유지하면서 Electron·React·TypeScript 앱의 유스케이스를 shared 계약·main·preload·renderer에 걸쳐 구현합니다.


함께 쓰는 core의 UC·업무 규칙·TC 정의·엔티티 모델·용어집을 바탕으로 $ARGUMENTS를 구현합니다. 수정 전에 기존 기능과 [아키텍처 안내](references/architecture.ko.md)를 읽습니다. 두 번째 IPC 경로·에이전트 연결·채팅 상태 저장소를 만들기보다 기존 구현을 맞춥니다. 동작이 모호하면 이번 변경에 영향을 주는 결정만 해결하며, 분석만 요청한 경우 문서에서 종료합니다.

## 경계를 따라 변경 연결

- 영향받는 UC 단계와 `UC-001 BR-001` 형식의 규칙을 shared 계약·main 핸들러/서비스·preload API·renderer 상태·테스트에 연결합니다. 기존 규칙 ID를 집행 코드 주석과 테스트 이름에 유지합니다. 프로세스 경계를 넘는다는 이유로 같은 규칙에 새 ID를 부여하지 않습니다.
- OS·파일시스템·브라우저·에이전트 권한은 main 또는 명시적으로 소유한 서비스 프로세스에 둡니다. Shared 모듈은 직렬화 가능한 타입과 Zod 스키마를 담으며 권한이 있는 구현을 담지 않습니다. Main은 동작 전에 발신자/프레임·페이로드·기능 권한·리소스 범위를 검증합니다. 타입이 맞는 것만으로 충분하지 않습니다.
- Preload는 작업별 메서드와 필터링된 이벤트 데이터, 구독 해제 경로를 노출합니다. 임의 채널·원시 `ipcRenderer`·Electron 이벤트 객체·범용 shell 명령·무제한 파일시스템 접근을 노출하지 않습니다.
- 앱에 있는 shadcn/ui·AI Elements 컴포넌트로 어댑터가 관리하는 스트리밍 상태를 표시합니다. 필요하면 `ai` 타입 전용 import를 쓰며 선택한 모델·도구 실행 경로를 유지합니다. `useChat`이나 provider 전송 도입은 외형적인 채팅 수정이 아니라 명시적인 런타임 아키텍처 결정이 필요합니다.
- 추론·도구 인자/결과·Markdown·Mermaid·링크·파일 미리보기는 신뢰하지 않는 콘텐츠로 취급합니다. 표시된 도구 텍스트를 실행하거나 모델 출력을 IPC 권한으로 바꾸지 않습니다. 정제·링크 규칙을 적용하고 크거나 잘못된 출력의 렌더링 작업량을 제한합니다.
- 명세에 있는 로딩·빈 상태·재연결·실패·취소·완료 상태를 지원합니다. 전송 메시지를 무조건 추가하지 말고 세션/실행별로 정렬·중복 제거한 이벤트를 반영합니다. 취소와 도구 동의는 실제 백엔드 결과를 반영해야 합니다.
- UC에 필요할 때만 터미널·파일 트리/감시/검색·문서 처리·telemetry를 도입합니다. 네이티브·리소스 작업은 범위가 좁은 main 소유 서비스로 제공하고 닫을 때 watcher·프로세스·이벤트 구독·브라우저 view를 정리합니다.

## 테스트와 완료

요청 범위의 테스트를 함께 구현하거나 `renderer-test`·`electron-test`로 집중 검증합니다. Provider/daemon 경계가 바뀌면 `agent-runtime`, 네이티브 의존성·컴파일 경로·배포 동작이 바뀌면 `package`를 사용합니다. 실행 가능한 검사를 수행하고 실패를 보존하며 mock 이벤트 재생과 실제 모델 실행을 구분합니다. `sync-docs` 또는 직접 작업으로 영향 문서를 갱신한 뒤 `spec-review`로 문서 정합성을 확인합니다. 우발적인 구현에 맞춰 미충족 요구사항을 바꾸지 말고 UC/BR 충족 범위·변경 파일·실제 검사·남은 누락을 보고합니다.
