# grill-with-docs 소개와 출처

> 휴먼 리뷰용 한글 번역입니다. 실행 원문: [원문 스냅샷](source/README.md). 번역과 자동 검사는 승인을 뜻하지 않으며, 검토 상태와 원문 SHA256은 [관리 목록](../../manifest.json)에서 확인합니다.

`grill-with-docs`는 코드베이스에 이미 존재하는 용어, 경계와 결정에 비추어 계획을 검증하는 Codex 스킬이다.

한 번에 하나의 구체적인 질문을 한다. 코드나 문서에서 답을 찾을 수 있으면 저장소를 먼저 확인한다. 확정된 도메인 용어는 `CONTEXT.md`에 기록한다. 되돌리기 어렵고, 맥락 없이는 의외로 보이며, 실제 대안 사이의 선택을 거친 결정에는 ADR을 제안할 수 있다.

이 버전은 독립 스킬로 묶여 있다. 자체 컨텍스트·ADR 형식을 포함하므로 다른 스킬 설치에 의존하지 않는다.
