# Codex 스킬 표시 정보

> 휴먼 리뷰용 한글 번역입니다. 실행 원문: [원문 스냅샷](../source/agents/openai.yaml). 번역과 자동 검사는 승인을 뜻하지 않으며, 검토 상태와 원문 SHA256은 [관리 목록](../../../manifest.json)에서 확인합니다.

| 필드 | 원문 값 | 한글 검토 설명 |
| --- | --- | --- |
| `interface.display_name` | `유스케이스 기반 SDD` | Codex에 표시할 이름 |
| `interface.short_description` | `요구사항을 유스케이스부터 구현·검증까지 연결합니다` | 화면에 표시할 짧은 설명 |
| `interface.default_prompt` | `Use $use-case-spec-driven-development to specify, decompose, and deliver this software goal through use cases.` | 이 소프트웨어 목표를 유스케이스로 명세화·작업분해하고 완성하도록 `$use-case-spec-driven-development`를 사용한다는 기본 호출 문구 |

이 파일은 YAML 설정을 검토하기 위한 설명이다. 실제 설치된 설정은 원문 스냅샷에 보존한다.
