# 한글 스킬 문서 정리 계획

기능과 새 스킬을 추가하기에 앞서 사용자가 실제 지시를 읽고 검토할 수 있는 문서를 마련한다.

기준은 최신 core 구조가 있는 저장소 커밋 `6bbfcf2ee40ec88b939c59d404a59554c761b680`이다. 이전 설치 작업은 `codex/skills-sh-codex` 브랜치에 보존하고, 문서 작업은 `codex/korean-skill-review`에서 진행한다.

1. `AGENTS.md`와 `CLAUDE.md`에 문서 우선 작업 원칙을 기록한다.
2. 저장소 35개 스킬의 전체 지시와 연결된 Markdown 참조·규칙·프롬프트, 플러그인 8개의 루트 README를 `docs/ko-skills/`에 번역한다. 실행 원문은 변경하지 않는다.
3. 사용자가 제시한 로컬 두 스킬은 별도 `local/` 구역에 검토용 원문 스냅샷과 번역을 둔다. 이를 core나 설치 목록에 추가하지 않는다.
4. 원문·번역 경로와 SHA256, 출처, 검토 상태를 관리 목록에 기록하고 읽기 전용 검사로 스킬 문서와 플러그인 README의 누락과 변경을 확인한다.
5. 한글 목록에서 core, workflow, stack과 로컬 자료를 찾을 수 있게 연결하고, 실제 휴먼 리뷰가 끝나기 전에는 승인으로 표시하지 않는다.
6. 문서 누락·원문 변경·번역 변경을 검사하는 검증을 실행하고 기존 upstream 보존 검사도 수행한다. 신규 스킬은 한국어 검토본, manifest, catalog, 설치·정책 테스트를 같은 변경에 포함한다.

코드·셸·PlantUML·BPMN 예제와 파서용 영어 표기는 원문을 보존한다. 이들의 실행 결과나 번역 의미의 정확성을 해시로 인증하지 않는다.
