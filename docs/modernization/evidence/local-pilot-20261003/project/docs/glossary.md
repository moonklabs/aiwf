# Glossary

> Status: Reviewed

| Term      | Definition                                                     | Avoid     |
|-----------|----------------------------------------------------------------|-----------|
| 제출자    | 지출 내역을 작성해 제출하는 사람.                              | 신청자    |
| 지출 내역 | 정산을 위해 제출하는 금액과 사용 내용의 묶음.                  | 경비 청구 |
| 승인자    | 제출된 지출 내역을 검토하고 승인 여부를 결정하는 사람.         |           |
