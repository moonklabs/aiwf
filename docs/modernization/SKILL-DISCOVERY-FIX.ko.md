# 새 스킬 설치·검색 오류 수정

작성: 2026-10-08. 상태: **`awaiting_review`**.

## 확인한 원인과 수정 계획

`aiwf@0.6.0`에 `docpilot`를 배포했지만 이 컴퓨터의 전역 CLI는 `0.5.0`이고, 사용자 범위 설치 기록에는 기존 25개 스킬만 있었다. npm CLI 갱신과 스킬 설치는 별도 작업이다.

새 CLI의 설치 계획도 재현했다. core 전체의 `source_digest`가 바뀌면서 기존 core 스킬 7개를 충돌로 표시했고, 추가 예정인 `aiwf-docpilot`의 설치까지 차단했다. 기존 스킬 파일이 실제로 바뀌었는지는 비교하지 않았다.

수정은 기존 설치 계약의 추가 설치 범위에 한정한다. 설치 파일이 기록된 해시와 일치하는지 먼저 확인하고, 번들 해시나 버전이 달라졌다면 현재 배포본을 같은 이름·참조 변환으로 준비해 스킬별 전체 리소스 해시를 비교한다. 두 내용이 같으면 기존 스킬을 유지하고 새 항목만 설치한다. 내용이 달라진 관리 대상, 로컬 수정본, 관리되지 않은 기존 폴더는 계속 충돌로 보존한다. 실제 기존 스킬 갱신·제거 기능은 추가하지 않는다.

## 완료 기준

- 이전 core 설치 기록에서 새 스킬만 누락된 상황을 회귀 테스트로 재현한다.
- 기존 스킬 내용이 같으면 새 스킬만 backend에 전달하고, 기존 설치 파일을 변경하지 않는다.
- 기존 스킬 내용이 달라졌거나 로컬 수정이 있으면 전체 설치를 차단한다.
- 이 컴퓨터의 CLI와 사용자 범위 설치를 갱신하고 기존 25개 및 `aiwf-docpilot`의 설치 해시를 검증한다.
- 실제 Codex `skills/list`를 `forceReload: true`로 호출해 `aiwf-docpilot`의 검색 결과와 활성 상태를 확인한다. 설치 기록만으로 호스트 검색 완료를 주장하지 않는다.
- 문서·회귀·배포 검증 결과를 아래에 기록한다. 자동 검사는 휴먼 승인이 아니다.

Codex UI 직접 확인은 컴퓨터 조작 도구가 Codex 앱 접근을 허용하지 않아 실행하지 못했다. app-server 검색은 실제 사용자 설정과 설치 폴더를 사용했다. 이미 열린 대화의 주입된 스킬 목록은 그 대화가 카탈로그를 다시 읽기 전까지 오래된 목록일 수 있다. 이 검증은 스킬 발견과 활성 상태에 한정하며 DocPilot로 대상 앱의 역공학을 수행한 결과는 아니다.

스킬 지시 원문은 변경하지 않았다. [DocPilot 한글 검토본](../ko-skills/aiwf-core/skills/docpilot/SKILL.ko.md)과 이 수정의 설치 계약은 의미 검토 대기 상태다. npm 게시와 GitHub 반영 결과는 확인 후 별도로 기록한다.
