# 기획 ↔ 디자인 ↔ 구현 대응표 (현재 상태만)

> 바뀌면 해당 줄을 덮어쓰고 날짜를 갱신한다. 기획 문서는 [requirements](../requirements.md)·[use_cases](../use_cases/UC-001-submit-expense.md)에 있다.

## 상태 값
| 값 | 뜻 |
|---|---|
| `기획 없음` | 디자인은 있으나 대응하는 UC/FR이 없다 |
| `기획 변경 필요` | 디자인 결정이 기존 UC/FR·제약과 다르다 |
| `기획 변경 대기` | UC/FR이 바뀌어 디자인 재검토가 필요하다 |
| `디자인 완료` | Figma 화면·컴포넌트가 있고 결정이 decisions.md에 있다 |
| `구현: 이전 디자인` | 기능은 코드에 있으나 새 디자인 적용 전이다 |
| `구현: 새 디자인` | 새 디자인을 코드에 적용했다 |
| `검증 완료` | 실제 앱에서 사람이 확인했다 |
